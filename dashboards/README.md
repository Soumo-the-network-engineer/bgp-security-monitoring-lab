# Dashboards

Dashboard definitions can expose:

- BGP peer state
- Session uptime/flaps
- Prefix counts
- Route announcements/withdrawals
- Suspicious AS-path changes
- Detection alerts

Dashboard exports must not contain embedded production credentials or bearer tokens.
